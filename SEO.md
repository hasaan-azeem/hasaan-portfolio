## 1. How SEO Is Built

The portfolio uses Vite with static prerendering and page-level SEO metadata.

- `npm run build` runs `vite build`, followed by `scripts/prerender.mjs`.
- Prerendering generates static HTML for the configured routes and `404.html` inside `dist/`.
- Page-level titles, descriptions, canonical URLs, Open Graph tags, Twitter metadata, and JSON-LD are managed through:
  - `src/seo/PageMeta.tsx`
  - `src/seo/site.ts`
- Site-wide Organization, Person, and WebSite schema is defined in `index.html`.
- `robots.txt`, `sitemap.xml`, and `llms.txt` are generated by the SEO plugin in `vite.config.ts`.

### Adding a New Page

Whenever a new page is added:

1. Add its route in `src/App.tsx`.
2. Add the route to `SITEMAP_PATHS` in `vite.config.ts`.
3. Add the route to `ROUTES` in `scripts/prerender.mjs`.
4. Add the appropriate `<PageMeta>` component.
5. Verify the generated HTML after building.

## 2. Environment Variables

Configure these in your hosting provider's environment settings.

| Variable | Purpose |
|---|---|
| `VITE_SITE_URL` | Production website URL used for canonical URLs, sitemap, and schema |
| `VITE_GSC_VERIFICATION` | Google Search Console HTML verification token |
| `VITE_BING_VERIFICATION` | Bing Webmaster Tools verification token |
| `VITE_GA_MEASUREMENT_ID` | Optional GA4 measurement ID override |

**Important:** Set `VITE_SITE_URL` to the actual production domain. If the portfolio moves to a custom domain, update this variable before redeploying.

## 3. After the First Production Deployment

### A. Verify the Website

Check the following URLs:

- `/robots.txt`
- `/sitemap.xml`
- `/llms.txt`
- `/`
- `/contact`

Also test an invalid URL to ensure the website returns the intended 404 response.

Check that:

- Canonical URLs use the production domain.
- HTTP redirects to HTTPS.
- The preferred domain resolves consistently.
- Internal links do not point to localhost.
- Every important page has a unique title and description.

### B. Google Search Console

Website: https://search.google.com/search-console

1. Add the production website as a property.
2. Complete domain or URL-prefix verification.
3. For HTML-tag verification, copy the token's `content` value into `VITE_GSC_VERIFICATION`.
4. Redeploy the website.
5. Complete verification.
6. Open the Sitemaps section and submit `sitemap.xml`.
7. Use URL Inspection to request indexing for the homepage and contact page.
8. Monitor indexing and search performance.

### C. Bing Webmaster Tools

Website: https://www.bing.com/webmasters

1. Add the production website.
2. Import the property from Google Search Console or verify it using the HTML meta tag.
3. Set `VITE_BING_VERIFICATION` if using meta-tag verification.
4. Submit the sitemap.
5. Monitor crawling and indexing.

### D. Google Analytics 4

- Open GA4 and check the Realtime report.
- Visit the website and confirm that page views are recorded.
- Test navigation between pages.
- Verify that contact and appointment interactions are tracked where configured.

### E. Validate Structured Data

Use these tools:

- Rich Results Test: https://search.google.com/test/rich-results
- Schema Markup Validator: https://validator.schema.org

Validate:

- Person schema
- WebSite schema
- Organization schema, only where appropriate
- Breadcrumb schema, where applicable
- FAQ schema, only when the page genuinely contains visible FAQs and meets Google's requirements

Also test Open Graph previews by sharing the homepage and contact page on LinkedIn, X, and WhatsApp.

### F. Performance

Use https://pagespeed.web.dev/

Test:

- Homepage, mobile
- Homepage, desktop
- Contact page, mobile
- Contact page, desktop

Prioritize:

- Largest Contentful Paint (LCP)
- Interaction to Next Paint (INP)
- Cumulative Layout Shift (CLS)
- Image optimization
- JavaScript loading
- Font loading
- Mobile responsiveness

## 6. Ongoing SEO Maintenance

### Weekly
- Check website availability.
- Review newly published content.
- Fix broken internal links.
- Verify newly added pages have metadata.

### Monthly
- Review Google Search Console performance.
- Identify queries generating impressions but few clicks.
- Review indexing issues.
- Monitor Core Web Vitals.
- Check GA4 traffic and engagement.
- Improve pages based on actual search data.

### Whenever Major Changes Are Made
- Rebuild and redeploy.
- Verify canonical URLs and metadata.
- Check sitemap updates.
- Test structured data.
- Request indexing for important updated pages.

## 7. Future Domain Decision

Consider acquiring a personal domain based on your professional identity, such as `hasaanazeem.com`, if available and suitable.

Before switching:

1. Choose the final domain.
2. Configure DNS and HTTPS.
3. Update `VITE_SITE_URL`.
4. Update canonical URLs and sitemap.
5. Configure permanent redirects from the previous domain.
6. Update Google Search Console and Bing Webmaster Tools.
7. Update your social profiles and external backlinks.

Avoid changing domains repeatedly. Establish one primary domain and build your long-term search presence around it.
